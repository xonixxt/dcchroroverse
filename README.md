# DC ChronoVerse

## Contexto
O projeto consiste em um site temático que apresenta a cronologia dos filmes do universo DC Extended Universe (DCEU), permitindo ao usuário visualizar os filmes em ordem narrativa.

## Público-alvo
Jovens e adultos fãs de filmes de super-heróis, que consomem conteúdo principalmente pelo celular e computador.

## Problema
Muitos usuários não sabem a ordem cronológica correta dos filmes da DC, dificultando a experiência de assistir de forma organizada.

## Critério de sucesso
O usuário consegue acessar a plataforma, visualizar os filmes em ordem cronológica e navegar para ver detalhes de cada filme facilmente.
